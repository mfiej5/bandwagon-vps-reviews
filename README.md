## 口碑的真实构成：稳定和线路是基本盘

把各家中文测评、长期用户反馈放在一起看，搬瓦工的好评集中在一个点上：**稳**。不是说它从不出故障，而是宕机的频率和时长控制得不错，这一点在 VPS 商家里属于长期第一梯队的表现。一个很能说明问题的细节是，它家自带自研的 KiwiVM 控制面板，重装系统、换机房、做快照、查流量都在面板里完成，对新手比命令行友好得多。

线路是第二个加分项。面向中国大陆的优化是搬瓦工的立身之本，第三方测评数据大致是这样的：洛杉矶 CN2 GIA 机房延迟在 150–180ms，电信用户体验尤其明显；香港 CN2 GIA 机房延迟可以低到 30–60ms，有香港套餐用户反馈晚高峰下载能跑到 700Mbps 以上，三网丢包率低于 1%。这些数字来自公开测评，不是官方宣传口径，参考价值更高。

短板也很清楚，买之前要心里有数：

- **没有 DDoS 防护**。所有套餐为保证双程优化线路都不提供防御，网站一旦被大流量攻击，IP 会被空路由处理，这是建站用户最需要权衡的一条。

- **没有企业级能力**。专线、复杂权限、审计这类需求它满足不了，定位始终是个人用户和小团队。

## 买之前容易踩的坑

**限量版能不能买到全看运气。** 官方没有固定补货时间表，等限量版等上几周是常态。刚需就买常规款，蹲限量是锦上添花的事。

**切换机房会影响流量。** 把套餐从普通机房切到 CN2 这类高成本线路时，可用流量会按比例缩减，比如 KVM 套餐切到 CN2 机房后流量只剩原来的三分之一。买之前算清楚自己的流量需求，别下单后再切。

**便宜套餐不能自选日本和香港机房。** 日本机房需要 CN2 GIA-E 及以上系列，香港是单独的套餐线。以为买最便宜的 KVM 就能切到东京的，下单前先看清楚机房范围。

**升级按差价补，不用重买。** 套餐可以在当前周期内直接升级，只需补剩余时长的差价，当场生效。先买低配再升级是可行的路径，不用担心被锁死。

**迪拜套餐谨慎选。** 同价位下流量比美国套餐少一半，除非业务真在中东，否则这个系列没有入手的理由。
